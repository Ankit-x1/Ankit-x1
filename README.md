# Ankit Karki

Software engineer and machine learning engineer focused on computer vision, model inference, and AI infrastructure. I enjoy connecting trained models to real hardware and building end-to-end systems whose performance can be measured in practice.

Areas of focus

- Computer vision and deep learning
- Edge inference and embedded machine learning
- MLOps and AI infrastructure
- Robotics and agentic automation

## How I work

I like taking projects from training through deployment: exporting a model, running it on constrained hardware, and measuring latency, accuracy, and model size. I aim to report trade-offs and limitations plainly, without rounding away the details that matter.
